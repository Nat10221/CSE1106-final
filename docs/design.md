The final product will allow one temperature to be input, and then if
that temperature is not in the range provided by defines at the top,
an LED light on our raspberri pi will light up. 

Once the user is prompted again, the light will reset.

If they select Y, they will be prompted for a second temperature, 
If they select N, the program will end.

All of the temperatures will be averaged and then that result 
as well as each of their statuses (as seen at input) will be displayed 
in a "temps" file.
