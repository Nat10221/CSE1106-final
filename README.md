# CSE1106-final

Project 1 Chosen -
Create a temperature monitoring system for a university facilities department

Our code will - 
	Allow users to input a temperature in Fahrenheit
	Determine if a temperature is within 68-76 degrees F
	Display NORMAL or WARNING status
	Calculate average of temperatures 
	Save readings with status to file
	Use an LED connected to a raspberry PI to indicate status
	Allow range to be changed
